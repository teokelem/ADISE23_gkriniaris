#Περιγραφή Παιχνιδιού

Στην αρχή του παιχνιδιού ο κάθε παίκτης διαλέγει χρώμα  εφόσον διαλέξει παίρνει 4 φιγούρες του ίδιου χρώματος απ' τις οποίες τις 3 τις τοποθετεί στη βάση του η οποία έχει το ίδιο χρώμα μ' αυτές και την 4η την τοποθετεί στην Αφετηρία. Ο κάθε παίκτης εφόσον έχει την σειρά του  ρίχνει το ζάρι και το πιόνι πάει στην αντίστοιχη θέση. Ο παίκτης ο οποίος φέρνει εξάρα παίζει 2 φορές συνεχόμενες. Επίσης μπορεί αν θέλει να βγάλει μια νέα φιγούρα στο παιχνίδι, αλλά αυτό το αποφασίζει μόνο ο ίδιος ο παίκτης. Κάθε παίκτης αφού κάνει όλο το γύρο του πίνακα 55 υπ΄αριθμόν κινήσεις για να τερματίσει το πιόνι του, Εάν τώρα ένας παίκτης ρίξει το ζάρι και η κίνησή του αυτή καταλήξει σε τετραγωνάκι στο οποίο βρίσκεται φιγούρα άλλου παίκτη, τοτε ξανατοποθετήσει πίσω στη βάση του απ' όπου θα ξαναβγεί μόνον όταν ο κάτοχός της φέρει εξάρα. Επιπρόσθετα το πρώτο κουτάκι χρώματος που πέφτει ο παίκτης είναι επίσης ασφαλές για όλα τα πιόνια. Νικητής είναι αυτός ο οποίος θα καταφέρει πρώτος να κάνει τον κύκλο και με τα 4 πιόνιο του χρώματός του.

###Board

####Ανάγνωση Board

GET /board/

Επιστρέφει το Board.

####Αρχικοποίηση Board

POST /board/

Αρχικοποιεί το Board, δηλαδή το παιχνίδι. Γίνονται reset τα πάντα. Επιστρέφει το Board στην αρχικη του μορφη.

###Piece

GET /board/piece/:x/:y/

####Μεταβολή Θέσης Πιονιού

PUT /board/piece/:x/:y/

###Status

####Ανάγνωση κατάστασης παιχνιδιού

GET /status/

Επιστρέφει το στοιχείο Game_status.



### Board
---------

Το board είναι πίνακας διαστασεων 15Χ15, οπου κάθε στοιχείο έχει τα παρακάτω:


| Attribute                | Description                                  | Values                              |
| ------------------------ | -------------------------------------------- | ----------------------------------- |
| `x`                      | H συντεταγμένη τετραγώνου x              | 1..15                                |
| `y`                      | H συντεταγμένη τετραγώνου y               | 1..15                                |
| `b_color`                | To χρώμα του τετραγώνου                      | 'R','G','B','Y','W','MIX','GR','RY','BY','GB'                             |
| `piece_color`            | To χρώμα του πιονιού                         |'R','G','B','Y'                         |
| `piece`                  | To Πιόνι που υπάρχει στο τετράγωνο           | 'Y1','Y2','Y3','Y4','R1','R2','R3','R4','B1','B2','B3','B4','G1','G2','G3','G4', null       |
| `y_path`                  | Πίνακας συντεταγμένων (x,y) που μπορουν να μετακινηθούν τα κίτρινα πιόνια.   | 
| `r_path`                  | Πίνακας συντεταγμένων (x,y) που μπορουν να μετακινηθούν τα κοκκινα πιόνια.   | 
| `b_path`                  | Πίνακας συντεταγμένων (x,y) που μπορουν να μετακινηθούν τα μπλε πιόνια.   | 
| `g_path`                  | Πίνακας συντεταγμένων (x,y) που μπορουν να μετακινηθούν τα πρασινα πιόνια.   | 

  |


### Players
---------

O κάθε παίκτης περιλαμβανει τις εξης πληροφοριες:


| Attribute                | Description                                  | Values                              |
| ------------------------ | -------------------------------------------- | ----------------------------------- |
| `username`               | Όνομα παίκτη                                 | String                              |
| `piece_color`            | To χρώμα που παίζει ο παίκτης                | 'R','G','B','Y'                             |
| `token  `                |  token του παίκτη(κρυφο). Επιστρέφεται μόνο οταν εισερχεται ο παίκτης στο παιχνίδι | HEX |


### Game_status
---------

H κατάσταση παιχνιδιού περιλαμβανει τις εξης πληροφοριες:


| Attribute                | Description                                  | Values                              |
| ------------------------ | -------------------------------------------- | ----------------------------------- |
| `status  `               | Κατάσταση             | 'not active', 'initialized', 'started', 'ended', 'aborded'     |
| `p_turn`                 | To χρώμα του παίκτη που παίζει        | 'B','R','G','Y',null                              |
| `result`                 |  To χρώμα του παίκτη που νικησε |'B','R','G','Y',null                              |
| `last_change`            | Τελευταία αλλαγή/ενέργεια στην κατάσταση του παιχνιδιού         | timestamp |
